Privacidade

Responsável pelo tratamento

Este site é mantido por Acacio Barros. Para questões relacionadas à privacidade ou aos seus dados pessoais, utilize o formulário de contato deste site.

Dados enviados pelo formulário

Quando você utiliza o formulário de contato, são processados seu nome, endereço de e-mail e a mensagem enviada. Esses dados são usados somente para receber e responder à sua correspondência. A base jurídica adotada para esse tratamento é o interesse legítimo em receber e responder às mensagens enviadas voluntariamente ao site.

O formulário é processado pelo Formspree. No plano atualmente utilizado por este site, o Formspree mantém o histórico das submissões por até 30 dias. As mensagens recebidas por e-mail podem ser conservadas pelo tempo razoavelmente necessário para responder e manter a correspondência, sendo eliminadas quando não forem mais necessárias, salvo quando houver uma razão jurídica legítima para conservá-las.

O Formspree pode processar dados nos Estados Unidos e informa utilizar as Cláusulas Contratuais Padrão da União Europeia para transferências internacionais de dados.

Hospedagem

Este site é hospedado pelo GitHub Pages. O GitHub informa que registra e armazena o endereço IP dos visitantes do GitHub Pages para fins de segurança. O tratamento realizado pelo GitHub está sujeito à própria política de privacidade do GitHub.

Idioma e armazenamento local

Na primeira visita, o site consulta localmente os idiomas preferidos configurados no navegador apenas para escolher entre português e inglês. Essa informação não é transmitida pelo código deste site nem utilizada para criar perfis ou rastrear visitantes.

Se você escolher manualmente um idioma, essa preferência é mantida em sessionStorage durante a sessão de navegação. O site também utiliza sessionStorage para manter estável, durante a sessão, a escolha aleatória do poema em destaque. Essas informações não são usadas para identificação, publicidade, análise de audiência ou rastreamento.

Cookies, publicidade e análise

O código deste site não utiliza cookies de publicidade, ferramentas de análise de audiência, pixels de rastreamento ou publicidade comportamental.

Links externos

Este site contém links para publicações, Instagram e outros sites externos. Ao seguir esses links, o tratamento de dados passa a ser regido pelas políticas dos respectivos serviços.

Seus direitos

Quando aplicável, você pode solicitar acesso, correção, eliminação ou limitação do tratamento dos seus dados pessoais, bem como se opor ao tratamento e exercer outros direitos previstos pela legislação de proteção de dados. Para fazer uma solicitação, utilize o formulário de contato.

Pessoas no Espaço Econômico Europeu também podem apresentar uma reclamação à autoridade de proteção de dados competente em seu país.

Privacy

Data controller

This site is maintained by Acacio Barros. For questions about privacy or your personal data, use the contact form on this site.

Contact-form data

When you use the contact form, your name, email address, and message are processed. These data are used only to receive and respond to your correspondence. The legal basis relied upon for this processing is the legitimate interest in receiving and responding to messages voluntarily sent through the site.

The contact form is processed by Formspree. Under the plan currently used by this site, Formspree retains submission history for up to 30 days. Messages delivered by email may be retained for as long as reasonably necessary to respond and maintain the correspondence and deleted when no longer needed, unless there is a legitimate legal reason to retain them.

Formspree may process data in the United States and states that it relies on the European Union Standard Contractual Clauses for international data transfers.

Hosting

This site is hosted by GitHub Pages. GitHub states that it logs and stores the IP addresses of visitors to GitHub Pages for security purposes. GitHub’s processing is governed by GitHub’s own privacy statement.

Language and local storage

On a first visit, the site locally reads the browser’s preferred languages only to choose between Portuguese and English. This information is not transmitted by this site’s code and is not used for profiling or tracking.

If you manually select a language, that preference is stored in sessionStorage for the browsing session. The site also uses sessionStorage to keep the randomly selected featured poem stable during the session. This information is not used for identification, advertising, audience analytics, or tracking.

Cookies, advertising, and analytics

This site’s own code does not use advertising cookies, audience-analytics tools, tracking pixels, or behavioral advertising.

External links

This site contains links to publications, Instagram, and other external websites. Once you follow those links, data processing is governed by the respective services’ privacy policies.

Your rights

Where applicable, you may request access to, correction or deletion of, or restriction of processing of your personal data, object to processing, and exercise other rights available under data-protection law. Use the site’s contact form to make a request.

Individuals in the European Economic Area may also lodge a complaint with the competent data-protection authority in their country.
